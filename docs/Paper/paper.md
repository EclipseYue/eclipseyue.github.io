# 论文笔记

## A SANITY CHECK FOR AI-GENERATED IMAGE DETECTION (ICLR 2025)

### 一句话总结

这篇论文关注 AI 生成图像检测任务中的评测可靠性：如果数据划分、生成器来源或后处理方式存在偏差，检测器可能学到的是数据集捷径，而不是真正可泛化的生成痕迹。

### 阅读关注点

- 论文如何定义“AI-generated image detection”。
- 使用了哪些生成模型和真实图像数据源。
- 是否讨论跨生成器、跨数据集、跨后处理的泛化。
- Sanity check 具体检查了哪些数据偏差。
- 对现有检测方法的结论是否稳健。
