# 线性代数

线性代数是机器学习、图形学和数值计算的基础。这里重点记录概念之间的关系，而不是只堆公式。

## 核心问题

- 向量如何表示对象。
- 矩阵如何表示线性变换。
- 线性方程组何时有解、解有多少。
- 特征值和特征向量如何描述变换的不变量。
- 正交、投影和分解如何简化计算。

## 知识框架

### 向量与矩阵

- 向量：既可以看作有序数组，也可以看作空间中的点或方向。
- 矩阵：可以看作线性变换，也可以看作一组列向量。
- 矩阵乘法：复合线性变换，或列向量的线性组合。

### 线性方程组

关注三个问题：

1. 是否有解。
2. 是否唯一。
3. 解空间如何描述。

常用工具：

- 高斯消元。
- 秩。
- 行空间、列空间、零空间。

### 特征值与特征向量

如果

$$
A\mathbf{x}=\lambda \mathbf{x}
$$

则 $\mathbf{x}$ 是矩阵 $A$ 的特征向量，$\lambda$ 是对应特征值。它表示线性变换中方向不变、长度按比例缩放的向量。

### 正交与投影

正交能把复杂问题拆成互不干扰的分量。投影常用于最小二乘、降维和误差分析。

## 常见分解

- LU 分解：用于解线性方程组。
- QR 分解：用于正交化和最小二乘。
- 特征分解：用于理解对称矩阵和动力系统。
- SVD：用于降维、推荐系统、图像压缩和低秩近似。
