### 1.2 计算机系统结构

!!! abstract "冯·诺依曼结构"
    计算机由**五大部分**组成：
    
    - **运算器（ALU）**：执行算术和逻辑运算
    - **控制器（CU）**：控制程序执行流程
    - **存储器（Memory）**：存储程序和数据
    - **输入设备**：数据输入
    - **输出设备**：结果输出

#### 重要寄存器

!!! note "存储器相关寄存器"
    - **MAR**（Memory Address Register）：存储器地址寄存器
    - **MDR**（Memory Data Register）：存储器数据寄存器

!!! note "运算器相关寄存器"
    - **ACC**（Accumulator）：累加器
    - **MQ**（Multiplier-Quotient）：乘商寄存器
    - **X**：操作数寄存器
    - **IX**（Index Register）：变址寄存器
    - **BR**（Base Register）：基址寄存器

!!! note "控制器相关寄存器"
    - **PSW**（Program Status Word）：程序状态字寄存器
    - **PC**（Program Counter）：程序计数器
    - **IR**（Instruction Register）：指令寄存器

#### 程序编译执行过程

!!! example "从源码到可执行文件"
    ```
    hello.c → hello.i → hello.s → hello.o → hello.exe
      源文件    预处理    汇编代码   目标文件   可执行文件
    ```

#### 指令执行过程

!!! important "指令执行的基本步骤"
    
    **1. 取指阶段：**
    ```
    PC → MAR → Memory → MDR → IR
    ```
    
    **2. 分析阶段：**
    ```
    OP(IR) → CU（控制单元分析操作码）
    ```
    
    **3. 执行阶段：**
    ```
    Address(IR) → MAR → Memory → MDR → ACC
    ```

### 1.3 计算机性能指标

#### 基本概念

!!! info "硬件性能参数"
    - **机器字长**：CPU一次能处理的二进制位数
    - **数据通路带宽**：数据总线的位数
    - **主存容量**：$2^{MAR} \times MDR$（地址空间×字长）

#### 运算速度指标

!!! tip "性能评估指标"
    
    **基本概念：**
    - **吞吐量**：单位时间内处理的任务数量
    - **响应时间**：从请求到完成的时间
    - **主频**：CPU时钟频率
    - **CPU时钟周期**：主频的倒数

!!! example "重要性能公式"
    
    **CPI（每指令周期数）：**
    $$CPI = \frac{CPU时钟周期数}{指令数}$$
    
    **IPS（每秒指令数）：**
    $$IPS = \frac{主频}{CPI}$$
    
    **CPU执行时间：**
    $$CPU执行时间 = \frac{CPU时钟周期数}{主频} = \frac{指令条数 \times CPI}{主频}$$
    
    **MIPS（每秒百万指令）：**
    $$MIPS = \frac{指令条数}{执行时间 \times 10^6} = \frac{主频}{CPI \times 10^6}$$
    
    **FLOPS（每秒浮点运算数）：**
    $$FLOPS = 每秒执行的浮点运算次数$$

!!! warning "性能指标使用注意"
    - CPI是衡量CPU效率的重要指标，越小越好
    - MIPS不能完全反映计算机性能，因为不同指令复杂度不同
    - FLOPS主要用于科学计算领域的性能评估

## 2. 数据表示和运算

### 2.1 数制与编码
#### 2.1.1 进制转换

!!! tip "十进制转二进制方法"
    
    **整数部分转换：**
    - 方法：不断除以2，取余数
    - 顺序：余数倒序排列（先余为低位，后余为高位）
    
    **小数部分转换：**
    - 方法：不断乘以2，取整数部分
    - 顺序：整数部分顺序排列（先整为高位，后整为低位）

!!! example "进制转换示例"
    
    **整数转换：** 13₁₀ → ?₂
    ```
    13 ÷ 2 = 6 ... 1
    6  ÷ 2 = 3 ... 0  
    3  ÷ 2 = 1 ... 1
    1  ÷ 2 = 0 ... 1
    ```
    结果：1101₂
    
    **小数转换：** 0.375₁₀ → ?₂
    ```
    0.375 × 2 = 0.75  → 取整数部分 0
    0.75  × 2 = 1.5   → 取整数部分 1
    0.5   × 2 = 1.0   → 取整数部分 1
    ```
    结果：0.011₂

#### 2.1.2 定点数表示

!!! abstract "定点数的两种形式"
    
    **定点整数：** 符号位 + 数值位，小数点固定在最低位之后
    - 格式：`S.XXXXXXX`（实际小数点在末尾）
    - 示例：`00000101` 表示 +5，`10000101` 表示 -5
    
    **定点小数：** 符号位 + 数值位，小数点固定在符号位之后
    - 格式：`S.XXXXXXX`（小数点在符号位后）
    - 示例：`0.1010000` 表示 +0.625，`1.1010000` 表示 -0.625

#### 2.1.3 编码方式

!!! important "四种编码方式对比"

| 编码方式 | 定义 | 求法 | 表示范围（n位） | 特点 |
|----------|------|------|-----------------|------|
| **原码** | 最高位为符号位，其余为绝对值 | 正数：直接转二进制<br>负数：符号位为1，数值位为绝对值 | $-(2^{n-1}-1)$ ~ $+(2^{n-1}-1)$ | 有±0，直观易懂 |
| **反码** | 正数同原码，负数数值位按位取反 | 正数：同原码<br>负数：符号位不变，数值位取反 | 同原码 | 有±0，是补码的中间步骤 |
| **补码** | 正数同原码，负数为反码+1 | 正数：同原码<br>负数：反码+1 | $-2^{n-1}$ ~ $+(2^{n-1}-1)$ | 0唯一，便于运算 |
| **移码** | 真值加上偏移量$2^{n-1}$ | $[X]_{移} = X + 2^{n-1}$ | 同补码 | 便于大小比较，用于浮点数指数 |

!!! example "8位编码示例（以±5为例）"
    
    | 编码方式 | +5 | -5 |
    |----------|----|----|
    | **原码** | `00000101` | `10000101` |
    | **反码** | `00000101` | `11111010` |
    | **补码** | `00000101` | `11111011` |
    | **移码** | `10000101` | `01111011` |

!!! note "变形补码（模4补码）"
    - **特点：** 符号位占两位
    - **编码：** 00表示正数，11表示负数
    - **用途：** 某些特殊运算场合

* 补充：两个互为相反数的数的补码可以通过互相取反加一得到。
* 补充：注意带符号整数用补码表示这种表述。

#### 2.1.4 编码方式的关系与特点

!!! tip "编码转换规律"
    
    **正数特点：**
    - 正数的原码、反码、补码完全相同
    
    **负数转换：**
    1. 原码 → 反码：符号位不变，数值位按位取反
    2. 反码 → 补码：反码的最低位加1
    3. 原码 → 补码：可直接通过反码中转
    
    **补码优势：**
    - 解决了0的唯一性问题（只有+0，没有-0）
    - 加减运算统一，便于硬件实现
    
    **移码特点：**
    - 编码值与真值单调对应，便于比较大小
    - 主要用于浮点数的指数部分

#### 2.1.5 C语言中的数值类型

!!! info "C语言整数类型"
    
    **无符号整数（unsigned int）：**
    - 表示范围：$0$ ~ $2^n - 1$
    - 特点：只能表示非负数，没有符号位
    
    **有符号整数（int）：**
    - 表示范围：$-2^{n-1}$ ~ $2^{n-1} - 1$
    - 编码方式：采用补码表示
    - 特点：最高位为符号位

!!! warning "类型转换注意事项"
    - **有符号与无符号转换：** 位模式不变，但解释方式改变
    - **溢出处理：** 超出表示范围时会发生截断
    - **位运算：** 逻辑右移补0，算术右移补符号位

### 2.2 运算方式和电路

#### 2.2.1 算术逻辑单元（ALU）

!!! abstract "ALU的功能"
    ALU是CPU的核心部件，负责执行算术运算和逻辑运算，是数据处理的核心。

##### ALU的基本信号

!!! info "ALU的输入输出信号"
    
    **输入信号：**
    - **A, B**：两个操作数输入
    - **Op_m**：操作模式选择信号
    - **Cin**：进位输入
    
    **输出信号：**
    - **F**：运算结果
    - **Cout**：进位输出
    - **ZF**：零标志位（结果为0时置1）
    - **OF**：溢出标志位（有符号数溢出时置1）
    - **SF**：符号标志位（结果为负时置1）
    - **CF**：进位标志位（无符号数溢出时置1）

#### 2.2.2 定点数运算

##### 原码运算

!!! note "原码加法运算规则"
    原码加法需要分四种情况讨论：
    
    1. **正数 + 正数**：直接相加，符号位为0
    2. **负数 + 负数**：绝对值相加，符号位为1
    3. **正数 + 负数**：绝对值相减，结果符号看绝对值大小
    4. **负数 + 正数**：同情况3
    
    **原码减法**：转换为加法运算（减数变为相反数后相加）

##### 补码运算

!!! important "补码运算的优势"
    补码运算可以将减法统一为加法，简化了运算电路的设计。

**补码转换规则：**

!!! tip "负数补码转换方法"
    **负数原码 → 补码：** 数值位取反加1
    
    **负数补码 → 原码：** 找到最右边的1，该位和右边保持不变，左边各位取反

##### 溢出检测

!!! warning "有符号数溢出判断"
    
    **溢出条件：**
    - **正 + 正 → 负**：上溢出
    - **负 + 负 → 正**：下溢出
    
    **检测方法：**
    
    1. **符号位判断法：**
       $$V = A_s B_s \overline{S_s} + \overline{A_s} \overline{B_s} S_s$$
    
    2. **进位判断法：**
       $$V = C_s \oplus C_{s-1}$$
       其中$C_s$是符号位进位，$C_{s-1}$是最高数值位进位
    
    3. **双符号位法：**
       $$V = S_{s1} \oplus S_{s2}$$
       使用两个符号位，异或结果为1表示溢出

!!! warning "无符号数溢出判断"
    
    **加法溢出：** 最高位产生进位（CF = 1）
    
    **减法溢出：** 最高位产生借位（CF = 0）
    
    **判断方法：** 检查结果是否超出 $0 \sim 2^n - 1$ 范围

### 2.3 浮点数的表示与计算

#### 2.3.1 浮点数基本格式

!!! abstract "浮点数组成"
    浮点数由**阶码**和**尾数**两部分组成：
    
    ```
    |<-----阶码E----->|<-----尾数M----->|
    |E_f|E1E2...E(n-1)|M_f|M1M2...M(n-1)|
    ```

**浮点数表示公式：**
$$N = r^E \times M$$

其中：
- **N**：浮点数的真值
- **r**：基数（通常为2）
- **E**：阶码，表示指数部分
- **M**：尾数，表示有效数字部分

#### 2.3.2 浮点数的特点

!!! warning "浮点数溢出问题"
    - **上溢出**：指数过大，超出表示范围
    - **下溢出**：指数过小，接近于0
    - **解决方案**：需要进行溢出检测和处理

!!! important "规格化要求"
    为了提高精度和唯一性，浮点数需要规格化：
    - **规格化形式**：尾数的最高位为1
    - **目的**：消除前导零，提高有效数字位数

!!! note "编码方式"
    - **阶码**：通常采用移码表示，便于比较大小
    - **尾数**：采用补码表示，包含符号位
    - **注意**：阶码和尾数要分别进行补码转换

#### 2.3.3 IEEE 754标准

!!! abstract "IEEE 754浮点数标准"
    国际通用的浮点数表示标准，定义了单精度和双精度两种格式。

##### 单精度浮点数（32位）

对应C语言中的`float`类型：

```
|符号(1)|<-----阶码E(8)----->|<-----尾数M(23)----->|
|S   31|30 bias          23 |22 frac            0|
```

##### 双精度浮点数（64位）

对应C语言中的`double`类型：

```
|符号(1)|<-----阶码E(11)----->|<-----尾数M(52)----->|
|S  63 |62 bias           52 |51 frac            0|
```

#### 2.3.4 IEEE 754编码规则

!!! tip "编码方式说明"
    
    **阶码编码：**
    - 采用**移码**表示
    - 偏移量：$2^{k-1}-1$（k为阶码位数）
    - 单精度偏移量：127
    - 双精度偏移量：1023
    
    **尾数编码：**
    - 采用**原码**表示（注意不是补码）
    - 隐含前导1：实际表示为 `1.M`
    - 只存储小数点后的部分

!!! warning "特殊值处理"
    IEEE 754标准中，阶码全0和全1有特殊用途：
    
    - **阶码全0**：表示非规格化数或零
    - **阶码全1**：表示无穷大或NaN（非数值）

!!! example "IEEE 754格式特点"
    
    **隐含位技术：**
    - 规格化数的尾数隐含前导1
    - 实际尾数为 `1.fraction`
    - 只存储小数点后的23位（单精度）或52位（双精度）
    
    **为什么偏移量是 $2^{k-1}-1$：**
    - 避免阶码为128时导致的特殊情况
    - 确保有足够的正负指数范围

#### 2.3.5 浮点数表示范围

!!! info "IEEE 754表示范围"
    
    **单精度浮点数（float）：**
    - 有效数字：约7位十进制数字
    - 指数范围：-126 ~ +127
    - 数值范围：约 $1.4 \times 10^{-45}$ ~ $3.4 \times 10^{38}$
    
    **双精度浮点数（double）：**
    - 有效数字：约15-16位十进制数字
    - 指数范围：-1022 ~ +1023
    - 数值范围：约 $4.9 \times 10^{-324}$ ~ $1.8 \times 10^{308}$

## 3. 存储系统

### 3.1 存储器层次结构

!!! abstract "存储器层次结构的目标"
    在容量、速度和成本之间找到最佳平衡点，构建高效的存储系统。

#### 存储器层次

!!! info "存储器层次结构（从快到慢）"
    ```
    CPU
     ↕
    寄存器（Register）
     ↕
    高速缓存（Cache）
     ↕
    主存储器（Main Memory）
     ↕
    辅助存储器（Secondary Storage）
     ↕
    离线存储（Offline Storage）
    ```

!!! tip "存储器工作原理"
    ```
     | ----------- |
    CPU ↔ Cache ↔ 主存 ↔ 辅存
     | ----------- |
    ```
    
    - **局部性原理**：程序访问存储器时具有时间局部性和空间局部性
    - **层次化管理**：每一层都是下一层的缓存

### 3.2 存储器分类

#### 按存取方式分类

!!! note "四种主要存取方式"
    
    **随机存取存储器（RAM - Random Access Memory）**
    - 任意地址的存取时间相同
    - 代表：主存、Cache
    
    **顺序存取存储器（SAM - Sequential Access Memory）**
    - 按地址顺序存取，存取时间与地址有关
    - 代表：磁带
    
    **直接存取存储器（DAM - Direct Access Memory）**
    - 直接定位到存储区域，然后顺序查找
    - 代表：磁盘
    
    **相联存储器（CAM - Content Addressable Memory）**
    - 按内容进行存取
    - 代表：Cache中的相联存储器

#### 按读写功能分类

!!! info "读写特性分类"
    
    **读写存储器（R/W Memory）**
    - 可以读出和写入信息
    - 代表：RAM、Cache、磁盘
    
    **只读存储器（ROM - Read Only Memory）**
    - 只能读出信息，不能写入
    - 代表：BIOS、固件程序

#### 按读出后信息变化分类

!!! warning "读出特性分类"
    
    **破坏性读出**
    - 读出信息后原存储信息被破坏
    - 需要重新写入恢复信息
    - 代表：**DRAM**（动态RAM）
    
    **非破坏性读出**
    - 读出信息后原存储信息保持不变
    - 代表：**SRAM**（静态RAM）、磁盘、光盘

### 3.3 主存储器

#### 存储器技术

!!! example "DRAM vs SRAM 对比"
    
    | 特性 | DRAM | SRAM |
    |------|------|------|
    | **存储原理** | 栅极电容存储 | 触发器存储 |
    | **读出方式** | 破坏性读出 | 非破坏性读出 |
    | **刷新需求** | 需要定期刷新 | 不需要刷新 |
    | **存取速度** | 较慢 | 较快 |
    | **功耗** | 较低 | 较高 |
    | **成本** | 较低 | 较高 |
    | **集成度** | 高 | 低 |
    | **应用** | 主存 | Cache |

#### DRAM刷新机制

!!! important "DRAM刷新的必要性"
    由于DRAM使用电容存储信息，电容会漏电，因此需要定期刷新以保持数据。

**刷新周期：** 通常为2ms

!!! note "三种刷新方式"
    
    **集中刷新**
    - 在特定时间段内集中完成所有行的刷新
    - 优点：刷新控制简单
    - 缺点：刷新期间不能进行正常读写
    
    **分散刷新**
    - 将刷新操作分散在正常的读写周期中
    - 优点：不影响正常读写
    - 缺点：降低存储器工作效率
    
    **异步刷新**
    - 将总刷新时间分配到各行，每行定时刷新
    - 优点：既保证刷新又不影响正常工作
    - 缺点：控制电路较复杂

#### 存储器性能指标

!!! tip "衡量存储器性能的主要指标"
    
    **存储容量**
    - 计算公式：字数 × 字长
    - 单位：字节（Byte）、千字节（KB）、兆字节（MB）等
    
    **存储速度**
    - **存取时间**：从发出读写命令到完成操作的时间
    - **存取周期**：连续两次独立操作之间的最小时间间隔
    
    **单位成本**
    - 每位存储成本：总成本 / 存储容量
    - 成本效益比是存储器选择的重要因素

### 3.4 外部存储器

#### 3.4.1 硬盘存储器

!!! info "磁盘存储器的组织结构"
    磁盘由多个盘片组成，每个盘片有两个记录面，每个记录面划分为多个磁道，每个磁道分为若干扇区。

##### 磁盘地址结构

!!! example "磁盘地址计算示例"
    如磁盘有16个盘面，256个磁道，每个磁道16个扇区，每个扇区需要16位二进制代码
    
    ```
    |驱动器号 | 柱面(磁道)8位| 盘面(磁头)4位| 扇区4位 |
    ```

##### 磁盘访问时间

!!! important "磁盘访问时间公式"
    **总访问时间 = 寻道时间 + 旋转等待时间 + 数据传输时间 + 控制器延迟**
    
    - **寻道时间**：磁头移动到目标磁道的时间
    - **旋转等待时间**：等待目标扇区转到磁头下的时间（平均为半圈时间）
    - **数据传输时间**：实际读写数据的时间
    - **控制器延迟**：控制器处理命令的时间

#### 3.4.2 RAID技术

!!! abstract "RAID（Redundant Array of Independent Disks）"
    独立磁盘冗余阵列，通过将多个磁盘组合来提高性能、可靠性或两者兼有。

!!! note "RAID级别对比"
    
    | RAID级别 | 特点 | 优势 | 缺陷 |
    |----------|------|------|------|
    | **RAID 0** | 无冗余和无校验的磁盘阵列 | 性能最高 | 无容错能力 |
    | **RAID 1** | 镜像磁盘阵列 | 容错能力强 | 存储效率低（50%） |
    | **RAID 2** | 采用纠错海明码的磁盘阵列 | 错误检测和纠正 | 实际应用少 |
    | **RAID 3** | 位交叉奇偶校验的磁盘阵列 | 单盘容错 | 写入性能受限 |
    | **RAID 4** | 块交叉奇偶校验的磁盘阵列 | 独立访问 | 校验盘成为瓶颈 |
    | **RAID 5** | 无独立校验的奇偶校验磁盘阵列 | 分布式校验 | 写入开销较大 |

#### 3.4.3 固态硬盘（SSD）

!!! tip "SSD相比传统硬盘的优势"
    - **访问速度快**：无机械延迟
    - **功耗低**：无机械部件
    - **抗震性好**：固态存储
    - **噪音小**：无机械噪音

### 3.5 Cache存储器

!!! abstract "Cache的基本原理"
    Cache是位于CPU和主存之间的高速缓冲存储器，利用程序的局部性原理提高系统性能。

#### 3.5.1 映射方式

!!! note "三种映射方式对比"
    
    **直接映射（Direct Mapping）**
    - 每个主存块只能映射到Cache中的一个特定位置
    - 映射简单，硬件开销小
    - 可能产生冲突，利用率较低
    
    **全相联映射（Fully Associative）**
    - 主存块可以映射到Cache中的任意位置
    - 冲突最少，利用率高
    - 硬件复杂，成本高
    
    **组相联映射（Set Associative）**
    - 直接映射和全相联映射的折中方案
    - 将Cache分成若干组，块可以映射到组内任意位置
    - 平衡了性能和成本

!!! tip "Cache行结构"
    Cache行通常包含以下部分：
    - **有效位（Valid bit）**：标识该行是否有效
    - **标记位（Tag）**：用于地址匹配
    - **数据块（Data block）**：存储的实际数据

#### 3.5.2 地址映射

!!! example "主存地址结构"
    主存地址通常分为三个部分：
    ```
    |    标记(Tag)    |   组索引(Index)   | 块内偏移(Offset) |
    ```
    
    - **标记**：用于Cache行的匹配
    - **组索引**：确定映射到哪个Cache组
    - **块内偏移**：确定块内的具体字节
