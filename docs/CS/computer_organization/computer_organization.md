# 计算机组成原理

!!! abstract "课程概述"
    本笔记涵盖计算机组成原理的核心内容，包括计算机系统结构、指令执行过程、性能评估等重要概念。

## 1. 计算机系统概述

### 1.2 计算机系统结构

!!! abstract "冯·诺依曼结构"
    计算机由**五大部分**组成：
    
    - **运算器（ALU）**：执行算术和逻辑运算
    - **控制器（CU）**：控制程序执行流程
    - **存储器（Memory）**：存储程序和数据
    - **输入设备**：数据输入
    - **输出设备**：结果输出

#### 重要寄存器

!!! note "存储器相关寄存器"
    - **MAR**（Memory Address Register）：存储器地址寄存器
    - **MDR**（Memory Data Register）：存储器数据寄存器

!!! note "运算器相关寄存器"
    - **ACC**（Accumulator）：累加器
    - **MQ**（Multiplier-Quotient）：乘商寄存器
    - **X**：操作数寄存器
    - **IX**（Index Register）：变址寄存器
    - **BR**（Base Register）：基址寄存器

!!! note "控制器相关寄存器"
    - **PSW**（Program Status Word）：程序状态字寄存器
    - **PC**（Program Counter）：程序计数器
    - **IR**（Instruction Register）：指令寄存器

#### 程序编译执行过程

!!! example "从源码到可执行文件"
    ```
    hello.c → hello.i → hello.s → hello.o → hello.exe
      源文件    预处理    汇编代码   目标文件   可执行文件
    ```

#### 指令执行过程

!!! important "指令执行的基本步骤"
    
    **1. 取指阶段：**
    ```
    PC → MAR → Memory → MDR → IR
    ```
    
    **2. 分析阶段：**
    ```
    OP(IR) → CU（控制单元分析操作码）
    ```
    
    **3. 执行阶段：**
    ```
    Address(IR) → MAR → Memory → MDR → ACC
    ```

### 1.3 计算机性能指标

#### 基本概念

!!! info "硬件性能参数"
    - **机器字长**：CPU一次能处理的二进制位数
    - **数据通路带宽**：数据总线的位数
    - **主存容量**：$2^{MAR} \times MDR$（地址空间×字长）

#### 运算速度指标

!!! tip "性能评估指标"
    
    **基本概念：**
    - **吞吐量**：单位时间内处理的任务数量
    - **响应时间**：从请求到完成的时间
    - **主频**：CPU时钟频率
    - **CPU时钟周期**：主频的倒数

!!! example "重要性能公式"
    
    **CPI（每指令周期数）：**
    $$CPI = \frac{CPU时钟周期数}{指令数}$$
    
    **IPS（每秒指令数）：**
    $$IPS = \frac{主频}{CPI}$$
    
    **CPU执行时间：**
    $$CPU执行时间 = \frac{CPU时钟周期数}{主频} = \frac{指令条数 \times CPI}{主频}$$
    
    **MIPS（每秒百万指令）：**
    $$MIPS = \frac{指令条数}{执行时间 \times 10^6} = \frac{主频}{CPI \times 10^6}$$
    
    **FLOPS（每秒浮点运算数）：**
    $$FLOPS = 每秒执行的浮点运算次数$$

!!! warning "性能指标使用注意"
    - CPI是衡量CPU效率的重要指标，越小越好
    - MIPS不能完全反映计算机性能，因为不同指令复杂度不同
    - FLOPS主要用于科学计算领域的性能评估

## 2. 数据表示和运算

### 2.1 数制与编码
#### 2.1.1 进制转换

!!! tip "十进制转二进制方法"
    
    **整数部分转换：**
    - 方法：不断除以2，取余数
    - 顺序：余数倒序排列（先余为低位，后余为高位）
    
    **小数部分转换：**
    - 方法：不断乘以2，取整数部分
    - 顺序：整数部分顺序排列（先整为高位，后整为低位）

!!! example "进制转换示例"
    
    **整数转换：** 13₁₀ → ?₂
    ```
    13 ÷ 2 = 6 ... 1
    6  ÷ 2 = 3 ... 0  
    3  ÷ 2 = 1 ... 1
    1  ÷ 2 = 0 ... 1
    ```
    结果：1101₂
    
    **小数转换：** 0.375₁₀ → ?₂
    ```
    0.375 × 2 = 0.75  → 取整数部分 0
    0.75  × 2 = 1.5   → 取整数部分 1
    0.5   × 2 = 1.0   → 取整数部分 1
    ```
    结果：0.011₂

#### 2.1.2 定点数表示

!!! abstract "定点数的两种形式"
    
    **定点整数：** 符号位 + 数值位，小数点固定在最低位之后
    - 格式：`S.XXXXXXX`（实际小数点在末尾）
    - 示例：`00000101` 表示 +5，`10000101` 表示 -5
    
    **定点小数：** 符号位 + 数值位，小数点固定在符号位之后
    - 格式：`S.XXXXXXX`（小数点在符号位后）
    - 示例：`0.1010000` 表示 +0.625，`1.1010000` 表示 -0.625

#### 2.1.3 编码方式

!!! important "四种编码方式对比"

| 编码方式 | 定义 | 求法 | 表示范围（n位） | 特点 |
|----------|------|------|-----------------|------|
| **原码** | 最高位为符号位，其余为绝对值 | 正数：直接转二进制<br>负数：符号位为1，数值位为绝对值 | $-(2^{n-1}-1)$ ~ $+(2^{n-1}-1)$ | 有±0，直观易懂 |
| **反码** | 正数同原码，负数数值位按位取反 | 正数：同原码<br>负数：符号位不变，数值位取反 | 同原码 | 有±0，是补码的中间步骤 |
| **补码** | 正数同原码，负数为反码+1 | 正数：同原码<br>负数：反码+1 | $-2^{n-1}$ ~ $+(2^{n-1}-1)$ | 0唯一，便于运算 |
| **移码** | 真值加上偏移量$2^{n-1}$ | $[X]_{移} = X + 2^{n-1}$ | 同补码 | 便于大小比较，用于浮点数指数 |

!!! example "8位编码示例（以±5为例）"
    
    | 编码方式 | +5 | -5 |
    |----------|----|----|
    | **原码** | `00000101` | `10000101` |
    | **反码** | `00000101` | `11111010` |
    | **补码** | `00000101` | `11111011` |
    | **移码** | `10000101` | `01111011` |

!!! note "变形补码（模4补码）"
    - **特点：** 符号位占两位
    - **编码：** 00表示正数，11表示负数
    - **用途：** 某些特殊运算场合

* 补充：两个互为相反数的数的补码可以通过互相取反加一得到。
* 补充：注意带符号整数用补码表示这种表述。

### 2.1.4 编码方式的关系与特点

!!! tip "编码转换规律"
    
    **正数特点：**
    - 正数的原码、反码、补码完全相同
    
    **负数转换：**
    1. 原码 → 反码：符号位不变，数值位按位取反
    2. 反码 → 补码：反码的最低位加1
    3. 原码 → 补码：可直接通过反码中转
    
    **补码优势：**
    - 解决了0的唯一性问题（只有+0，没有-0）
    - 加减运算统一，便于硬件实现
    
    **移码特点：**
    - 编码值与真值单调对应，便于比较大小
    - 主要用于浮点数的指数部分

### 2.1.5 C语言中的数值类型

!!! info "C语言整数类型"
    
    **无符号整数（unsigned int）：**
    - 表示范围：$0$ ~ $2^n - 1$
    - 特点：只能表示非负数，没有符号位
    
    **有符号整数（int）：**
    - 表示范围：$-2^{n-1}$ ~ $2^{n-1} - 1$
    - 编码方式：采用补码表示
    - 特点：最高位为符号位

!!! warning "类型转换注意事项"
    - **有符号与无符号转换：** 位模式不变，但解释方式改变
    - **溢出处理：** 超出表示范围时会发生截断
    - **位运算：** 逻辑右移补0，算术右移补符号位

### 2.3 浮点数的表示与计算

#### 2.3.1 浮点数基本格式

!!! abstract "浮点数组成"
    浮点数由**阶码**和**尾数**两部分组成：
    
    ```
    |<-----阶码E----->|<-----尾数M----->|
    |E_f|E1E2...E(n-1)|M_f|M1M2...M(n-1)|
    ```

**浮点数表示公式：**
$$N = r^E \times M$$

其中：
- **N**：浮点数的真值
- **r**：基数（通常为2）
- **E**：阶码，表示指数部分
- **M**：尾数，表示有效数字部分

#### 2.3.2 浮点数的特点

!!! warning "浮点数溢出问题"
    - **上溢出**：指数过大，超出表示范围
    - **下溢出**：指数过小，接近于0
    - **解决方案**：需要进行溢出检测和处理

!!! important "规格化要求"
    为了提高精度和唯一性，浮点数需要规格化：
    - **规格化形式**：尾数的最高位为1
    - **目的**：消除前导零，提高有效数字位数

!!! note "编码方式"
    - **阶码**：通常采用移码表示，便于比较大小
    - **尾数**：采用补码表示，包含符号位
    - **注意**：阶码和尾数要分别进行补码转换

#### 2.3.3 IEEE 754标准

!!! abstract "IEEE 754浮点数标准"
    国际通用的浮点数表示标准，定义了单精度和双精度两种格式。

##### 单精度浮点数（32位）

对应C语言中的`float`类型：

```
|符号(1)|<-----阶码E(8)----->|<-----尾数M(23)----->|
|S   31|30 bias          23 |22 frac            0|
```

##### 双精度浮点数（64位）

对应C语言中的`double`类型：

```
|符号(1)|<-----阶码E(11)----->|<-----尾数M(52)----->|
|S  63 |62 bias           52 |51 frac            0|
```

#### 2.3.4 IEEE 754编码规则

!!! tip "编码方式说明"
    
    **阶码编码：**
    - 采用**移码**表示
    - 偏移量：$2^{k-1}-1$（k为阶码位数）
    - 单精度偏移量：127
    - 双精度偏移量：1023
    
    **尾数编码：**
    - 采用**原码**表示（注意不是补码）
    - 隐含前导1：实际表示为 `1.M`
    - 只存储小数点后的部分

!!! warning "特殊值处理"
    IEEE 754标准中，阶码全0和全1有特殊用途：
    
    - **阶码全0**：表示非规格化数或零
    - **阶码全1**：表示无穷大或NaN（非数值）

!!! example "IEEE 754格式特点"
    
    **隐含位技术：**
    - 规格化数的尾数隐含前导1
    - 实际尾数为 `1.fraction`
    - 只存储小数点后的23位（单精度）或52位（双精度）
    
    **为什么偏移量是 $2^{k-1}-1$：**
    - 避免阶码为128时导致的特殊情况
    - 确保有足够的正负指数范围

#### 2.3.5 浮点数表示范围

!!! info "IEEE 754表示范围"
    
    **单精度浮点数（float）：**
    - 有效数字：约7位十进制数字
    - 指数范围：-126 ~ +127
    - 数值范围：约 $1.4 \times 10^{-45}$ ~ $3.4 \times 10^{38}$
    
    **双精度浮点数（double）：**
    - 有效数字：约15-16位十进制数字
    - 指数范围：-1022 ~ +1023
    - 数值范围：约 $4.9 \times 10^{-324}$ ~ $1.8 \times 10^{308}$
