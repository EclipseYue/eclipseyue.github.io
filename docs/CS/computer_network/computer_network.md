## Ch1.计算机网络体系结构

### 1.1 计算机网络概述

#### 1.1.1 概念
若干结点和链路组成的网络

网络连计算机, 互连网通过路由器连网络.

#### 1.1.2 组成

**组成部分**: 硬件软件协议

- 硬件: 主机、通信链路、交换设备、通信处理机
- 软件: 资源共享软件、工具软件
- 协议: 核心 规定数据传输规范

**工作方式**: 边缘部分和核心部分

- 边缘部分: 用户主机
- 核心部分: 网络&路由器

**功能组成**: 通信子网和资源子网

- 通信子网: 传输介质、通信设备、网络协议
- 资源子网: 实现资源共享功能的设备及其软件

#### 1.1.3 功能

功能:

- 数据通信
- 资源共享
- 分布式处理
- 提高可靠性
- 负载均衡

#### 1.1.4 交换

**电路交换:**
- 传统电话网
- 连接建立、数据传输、链接释放
- 优点: 通信时延小、有序传输、没有冲突、适用范围广、实时性强、控制简单
- 缺点: 建立连接时间长、线路利用性差、灵活性差、难以规格化、难以实现差错控制

**报文交换:**
- 报文: 用户数据加上源地址、目的地址等信息, 封装, 采取**存储转发技术**
- 优点: 无须建立连接、动态分配线路、线路可靠性高、线路利用率高、提供多目标服务
- 缺点: 转发时延高、缓存开销大、错误处理低效

**分组交换:**
- 采用**存储转发技术**
- 报文过长分组, 数据段前段加入首部
- 优点: 无建立时延、线路利用率高、简化储存管理、加速传输、减小出错概率和重发数据量
- 缺点: 存在存储转发时延、需要传输额外的信息量、可能出现失序、丢失或重复分组

#### 1.1.5 分类

分类:

- **分布范围分类**: 广域网WAN、城域网MAN、局域网LAN、个人区域网PAN
- **传输技术**: 广播式网络、点对点网络
- **拓扑结构**: 总线形、星形、环形、网状
- **使用者**: 公用网、专用网

#### 1.1.6 指标

1. **速率**: 数据传输速率、数据传输率、数据率或比特率, 单位为b/s bit/s bps
2. **带宽**: 原指通过的信号频率范围, Hz, 在计网中指**最高数据传输速率**, 单位为b/s
3. **吞吐量**: 单位时间通过某个网络的实际数据量
4. **时延**: 由四个部分构成: 发送时延、传播时延、处理时延和排队时延
   - 发送时延/传输时延: 结点将分组所有比特推向链路所需的时间
   - 传播时延: 一个比特从链路一端传播到另一端所需的时间
   - 处理时延: 数据在交换结点存储穿法花费的时间
   - 排队时延: 进入路由器后在输入队列中排队等待处理, 在输出队列排队等待转发

5. **时延带宽积**: 传播时延*信道带宽
6. **往返时延(Round-Trip Time RTT)**: 从发送端发出一个短分组, 到发送端收到来自接收端的确认总共经历的时延
7. **信道利用率**: 有数据通过时间/数据通过时间

#### 1.2 计算机网络体系结构与参考模型
计算机网络的各层及其协议的集合称为网络的体系结构。

对等层之间传输的数据单位称为该层的协议数据单元（PDU）,
SDU是服务数据单元, 是上层传递给下层的PDU。
PCI是协议控制信息, 是PDU中用于控制和管理的部分。

#### 1.2.2 协议接口服务
协议：如TCP/IP中两个结点A和B的传输层之间存在协议

组成：由语法、语义、同步三部分组成。

接口：SAP服务访问点，紧邻的层定义接口

服务：下层为紧邻的上层提供的垂直功能调用

上层与下层通过服务原语交互

原语分为以下四类
- **请求Request**: 上层向下层发出请求
- **指示Indication**: 下层向上层发出指示
- **响应Response**: 下层对上层请求的响应
- **证实Confirmation**: 上层对下层指示的确认

本层协议实现来提供上层服务 协议水平 而服务垂直

服务分类：
- 面向连接与无连接
- 可靠服务和不可靠服务
- 有应答服务和无应答服务


#### 1.2.3 参考模型
OSI参考模型：开放系统互联参考模型
- 应用层：用户与网络之间的交互
- 表示层：定义数据结构，标准编码形式、数据压缩加密解密
- 会话层：建立同步、检查点
- 传输层：流量控制、差错控制、服务质量、数据传输 端到端通信
- 网络层：流量控制、拥塞控制、差错控制和网际互联
- 数据链路层：加强物理层传输比特流功能，无差错数据链路
- 物理层：电路接口 信号电气

TCP/IP参考模型
- 应用层：HTTP、FTP、SMTP、DNS
- 传输层：TCP、UDP
- 网际层：IP、ICMP、ARP、RARP
- 网络接口层：以太网、PPP、FDDI
