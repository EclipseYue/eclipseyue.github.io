这页作为 C++ 学习入口，具体内容拆在下面两篇笔记中：

- [C++ 八股](cpp_baguette.md)

## 学习主线

1. 语法基础：类型、表达式、控制流、函数。
2. 面向对象：类、构造析构、继承、多态。
3. 资源管理：指针、引用、RAII、智能指针。
4. STL：容器、迭代器、算法、适配器。
5. 现代 C++：auto、lambda、右值引用、移动语义。
6. 工程实践：编译、链接、CMake、调试和性能分析。

## 面试重点

- 对象生命周期。
- 虚函数和多态。
- 内存管理。
- 拷贝控制。
- STL 底层结构。
- 多线程基础。
