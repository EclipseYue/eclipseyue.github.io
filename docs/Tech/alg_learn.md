#### 5. 接口调用（sort函数）示例（C++）

```cpp
#include <algorithm>
#include <vector>
#include <iostream>
using namespace std;
bool cmp(int a, int b) {
    return a < b; // 升序排序
}
int main() {
    vector<int> arr = {5, 2, 9, 1, 5, 6};
    sort(arr.begin(), arr.end(), cmp);
    for (int num : arr) {
        cout << num << " ";
    }
    return 0;
}
```

## 训练节奏

1. 先做暴力和模拟，保证能把题意转成代码。
2. 再练基础数据结构和搜索，建立模板熟练度。
3. 动态规划不要急着背结论，先写状态定义和转移含义。
4. 图论和字符串算法适合按专题集中刷。
