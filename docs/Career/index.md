# 求职导航

这里放求职相关内容：简历、投递、笔试、面试、项目表达和复盘。它和工程技术分开，是为了避免把“为了找工作整理的材料”和“长期可复用的技术笔记”混在一起。

## 目录

- [26 秋招记录](26fall_recruitment_record.md)：投递、准备节奏、面试复盘和待补内容。
- [简历摘要](cv.md)：正式简历的精简版，保留教育、经历、项目和技能主线。
- [简历复习](resume_review.md)：项目表达、技术亮点、个人贡献和可追问细节。

## 维护方式

- 面试当天记录真实问题和当时回答。
- 对答得差的问题，回到对应技术目录补成系统笔记。
- 正式简历只保留高密度表达，细节放到简历复习页。
- 阶段复盘尽量沉淀为 checklist，而不是只保留情绪记录。
